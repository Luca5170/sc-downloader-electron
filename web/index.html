Caricamento sul NAS

A fine download il file viene spostato sul NAS via SFTP e rinominato come vogliono i media server.

Serve SSH attivo sul NAS (porta 22), l'FTP non basta. La password viene salvata nella Gestione credenziali di Windows; in Docker in un file della cartella data.

Web UI di qBittorrent

Avanzate · Docker

Se qBittorrent e questa app vedono la cartella dei download con percorsi diversi (per esempio in Docker), scrivi come la chiama l'uno e come la chiama l'altra.

Per vedere l'avanzamento e la scheda tecnica serve la Web UI: in qBittorrent apri Strumenti → Opzioni → Web UI, attivala con la porta 8090 (la 8080 è spesso occupata) e spunta «Salta l'autenticazione per i client su localhost».
